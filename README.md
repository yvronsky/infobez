# Infobez — Информационная безопасность

Проект для подготовки и ведения информации об информационной безопасности.

## Структура

```
infobez/
├── docs/          — теория, стандарты, руководства
├── checklists/    — чеклисты проверок и аудитов
├── incidents/     — журнал инцидентов и разборы
├── policies/      — политики и регламенты
├── notes/         — рабочие заметки и черновики
└── templates/     — шаблоны документов
```

## Ключевые документы

- `docs/` — ISO 27001, NIST, ГОСТ, обзоры угроз
- `checklists/` — чеклисты для пентестов, аудитов, харденинга
- `incidents/` — шаблон разбора инцидента, журнал
- `policies/` — политика ИБ, регламенты доступа, пароли

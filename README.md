# Infobez — Информационная безопасность

База знаний и рабочие материалы по информационной безопасности для группы компаний финансового/финтех-сектора.

## Содержание

### docs/ — Документация и аналитика

| Файл | Описание |
|------|----------|
| `action-plan-org.md` | Предложения по организационным изменениям в рамках ИБ (приоритеты 1-3) |
| `org-measures.md` | Организационные меры ИБ: разделение полномочий, минимальные привилегии, классификация данных и др. |
| `incident-response-overview.md` | Немедленные действия при инциденте с финансовым ущербом |
| `org-presence-meetings.md` | Анализ роли офисного присутствия и встреч для ИБ |
| `threat-model-structure.md` | Структура документа «Модель угроз» (активы, субъекты, векторы, оценка) |
| `threat-model-gemma-prompt.md` | Системный промпт для LLM в роли офицера ИБ (ведение модели угроз) |
| `topics.md` | Перечень тем и направлений ИБ (стандарты, управление рисками, техзащита, нормативные требования РФ) |

### incidents/ — Журнал инцидентов

| Файл | Описание |
|------|----------|
| `journal.md` | Журнал инцидентов ИБ (табличный формат с ID, датой, критичностью, статусом) |

### templates/ — Шаблоны документов

| Файл | Описание |
|------|----------|
| `incident.md` | Шаблон разбора инцидента ИБ (описание, хронология, root cause, меры) |
| `checklist.md` | Шаблон чеклиста проверки ИБ (разделы, пункты, статусы) |

## Ключевые темы

- **Стандарты**: ISO 27001, NIST CSF, ГОСТ Р ИСО/МЭК 27001, CIS Controls
- **Организационные меры**: разделение полномочий, аудит доступов, политики ИБ, обучение персонала
- **Управление рисками**: модель угроз, оценка и обработка рисков
- **Техническая защита**: харденинг, пентестинг, SIEM, мониторинг, DLP
- **Реагирование на инциденты**: процесс, форензика, разборы
- **Нормативные требования РФ**: 152-ФЗ, 187-ФЗ, приказы ФСТЭК/ФСБ

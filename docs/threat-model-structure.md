# Структура документа «Модель угроз»

**1. Введение**
Один абзац: цели документа, область применения (перечень компаний), ответственный за актуализацию, периодичность пересмотра.

**2. Ценные активы (что защищаем)**
- Финансовые активы: фиат, крипта, ценные бумаги, расписки
- Данные: клиентские, финансовая отчётность, учётные данные, ключи доступа
- Системы: банковские/платёжные системы, CRM, бухгалтерия, криптокошельки
- Физические активы: серверы, рабочие станции, носители

**3. Субъекты угроз (кто может навредить)**
- Внешние: хакеры, конкуренты, мошенники, социальные инженеры
- Внутренние: сотрудники (намеренно или по халатности), подрядчики
- Комбинированные: сговор инсайдера с внешним злоумышленником
- Регуляторы и соответствующие органы: проверки, запросы, изъятие данных/активов

**4. Векторы атак (как именно)**
- Технические: фишинг, взлом систем, перехват данных, подбор паролей
- Социальные: манипуляция сотрудниками, подмена реквизитов (BEC)
- Физические: кража устройств, несанкционированный доступ в помещения
- Внутренние: злоупотребление полномочиями, кража данных, саботаж

**5. Реестр угроз**
Таблица: угроза → актив → вектор → вероятность → ущерб → итоговый риск.

**6. Существующие меры защиты**
Что уже внедрено — технические и организационные меры.

**7. Регулярные процедуры**
Процедуры, которые должны выполняться на постоянной основе для минимизации угроз и выявления новых:
- Периодические: аудит доступа, пересмотр модели угроз, обучение персонала
- Непрерывные: мониторинг систем, контроль аномалий, сбор сигналов от сотрудников
- Триггерные: действия при инциденте, при увольнении сотрудника, при смене должности

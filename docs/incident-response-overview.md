# Меры при инциденте с финансовым ущербом

## Немедленные действия

1. Сохранить все логи в неизменном виде прямо сейчас
2. Ограничить доступ подозреваемых до завершения расследования
3. Привлечь внешних форензик-специалистов (чтобы не было конфликта интересов)
4. Зафиксировать хронологию в журнале инцидентов

## Организационные меры (по приоритету)

См. [org-measures.md](org-measures.md)

## Технические меры

### Мониторинг и аудит
- Логирование всех действий с финансовыми системами (кто, когда, что)
- SIEM или централизованный сбор логов
- Алерты на аномалии: нетипичное время входа, массовая выгрузка данных, крупные переводы
- Хранение логов в недоступном для рядовых сотрудников месте

### Контроль доступа
- MFA на всех финансовых и критичных системах
- Разделение сред: финансовые системы изолированы от общей сети
- Запрет использования личных устройств для работы с чувствительными данными
- Сессионный таймаут, блокировка экрана

### Защита от утечек (DLP)
- Контроль передачи файлов наружу (email, USB, облако)
- Запрет или мониторинг личной почты / мессенджеров на рабочих устройствах
- Водяные знаки / метки на финансовых документах — упрощают атрибуцию утечки

### Финансовые системы
- Двухфакторное подтверждение платёжных поручений
- Лимиты на операции без дополнительного согласования
- Разделение ролей: кто создаёт платёж — не тот, кто его подтверждает
